Ultrasonic Parking Sensor
=========================

A rear parking sensor model built on a Raspberry Pi Pico W in MicroPython.
Two HC-SR04 ultrasonic sensors measure the distance to an obstacle, a
Nokia 5110 display shows the distances and a car-style distance indicator,
a passive buzzer beeps faster as the obstacle gets closer and a simplified
rear collision warning blinks red hazard LEDs when an obstacle approaches
fast.

The full project description, wiring and test results are in the
`README on GitHub <https://github.com/Szalo03/Ultrasonic-distance-instrument>`_.

Authors: Marek Šádek, Marek Gláser, Dávid Szalay
